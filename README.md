# lajiovo-autotools 🐾

`lajiovo-autotools` 是一个集成了自动化运维、远程控制、轻量工具箱与辅助自动化脚本的 Python/Playwright 工具库，由开发者与 AI 协作完成。适用于日常任务处理、模拟器看护、消息中转与智能推送等场景。

---

## ⚙️ 核心功能

### 1. 🎮 AzurPilot & MuMu 模拟器看护与消息中转

* 🙈 **后台隐藏运行**：支持将模拟器与 AzurPilot 隐藏置于后台运行，具备自动重启机制。


* 🔄 **崩溃监测与恢复**：实时监控模拟器运行状态，遭遇卡死或异常崩溃时自动触发重启策略。


* 🌐 **网页自动化**：基于 Playwright 实现 AzurPilot 的自动化启动与更新。


* 📲 **消息解析与多端推送**：开放 `25566` 端口接收 Push 消息，可自动解析消息内容并执行处理，同步推送到手机 Bark App 及 QQ 群。


* 🧹 **广告弹窗清理（可选）**：提供可选的弹窗清理逻辑，按需自动拦截并清理 MuMu 模拟器的广告弹窗。



### 2. 🤖 QBot 管理助手（独立服务 Port: 25567）

* 💬 **多场景交互与昵称支持**：支持群聊与私聊模式，具备用户昵称识别与响应能力。


* 🎮 **娱乐与互动**：内置简易小游戏互动功能。


* 📜 **OP 指令与富媒体交互**：提供管理员（OP）控制指令集，支持 `Markdown` 格式排版、富媒体消息、自定义卡片以及自定义键盘（`Keyboard`）交互。


* 📊 **日志与截图可视化**：支持在聊天交互界面中实时翻页查看本地服务运行日志，并可调取查看错误截图。


* 🖥️ **WebUI 后台管理**：提供带密码验证的 WebUI 管理后台，支持群聊和私信，支持加载昵称。


* 🔌 **云崽 Bot 协议接入与扩展**：支持基于 `WebSocket` 与 `OneBot v11` 协议链接云崽 Bot（Yunzai-bot），可通过虚构 ID 转发消息，并支持 `phi-plugin` 等插件扩展（*提示：此板块目前存在一定 Bug 与不稳定性*）。



### 3. 📚 轻之国度电子书抓取工具

* 🕵️ **伪装抓取与插图处理**：基于 Playwright 模拟移动端浏览器行为，根据 `bookid` 抓取小说，自动下载并补齐处理文章插图。


* 💾 **细粒度缓存与断点续传**：缓存按“书-卷-章”分级分模块保存，支持断点续传；自动整合打包生成标准 EPUB 电子书。


* 💻 **Tk GUI 界面**：提供简易的 Tkinter 图形界面，方便直观地浏览与查看本地已缓存的电子书。



### 4. 🏰 主控核心大本营

* 🎛️ **集中调度与控制**：作为系统的主控节点，可调度其它几乎所有子功能模块，并支持随时暂停与恢复运行。


* 📅 **日常打卡与定期巡检**：支持自动执行每日签到打卡任务，并按设定周期自动去检查和巡视 AzurPilot 及 MuMu 模拟器的运行状态。


* 🛡️ **安全权限与防重复运行**：严格校验管理员权限，并构建防重复启动屏障，防止多进程冲突。


* 🛟 **进程守护与开机自启**：具备完善的异常捕获机制，即便遭遇报错也会守护进程挂机运行；支持配置系统开机自动启动（需手动在系统中完成配置）。


* 🔀 **隧道转发**：支持 Cpolar HTTP 隧道转发，将不同板块服务映射至不同端口。


* 🌐 **可视化导航与控制面板**：自带导航网页与控制面板网页，方便集中管理各服务状态与快捷跳转。



### 5. 🛠️ 百宝箱自动化扩展

* ⚡ **Cpolar 隧道极速启动**：支持直接运行 Cpolar 隧道获取公网地址，30 分钟后自动下架；自带端口转发，覆盖 `22267`、`25566`、`25567` 等端口。


* 🌐 **代理浏览器一键启动**：内置一键启动代理浏览器，支持文件下载、剪切板穿透以及登录 Session/Cookie 信息保存。


* ⚙️ **多维度代理配置管理**：支持一键修改代理配置，包含本程序（lk 配置及浏览器代理）与全局 Git 代理配置。


* 🍎 **苹果软件站签到**：基于 Playwright 模拟网页端完成自动化签到（含异常容错处理）。


* 🎵 **MusicDL 音乐分享**：一键后台启动 MusicDL 并将服务广播至局域网。


* 🎬 **FFmpeg 音频瘦身**：自动调用 FFmpeg 对下载的音频进行压缩瘦身，节省存储空间。


* 🔔 **Bark 推送接口**：提供轻量化的 Bark 消息推送 API 接口。


* 📝 **日志轮转管理**：配置自动日志轮转，防止日志文件过度占用磁盘空间。
